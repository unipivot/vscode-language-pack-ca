#  Paquet d'idioma català per al VS Code

El paquet d'idioma català proporciona una interfície d'usuari localitzada per al VS Code.

## Ús

Podeu substituir l'idioma per defecte de la interfície si definiu explícitament l'idioma de visualització del VS Code amb l'ordre **Configura l'idioma de visualització** (*Configure Display Language* en anglès).

Premeu `Ctrl+Shift+P` per obrir la **Paleta d'ordres** i, tot seguit, comenceu a escriure `display` per filtrar i mostrar l'ordre **Configura l'idioma de visualització**.

Premeu `Enter` per mostrar una llista dels idiomes instal·lats, amb l'idioma actual ressaltat. Seleccioneu un altre idioma per canviar l'idioma de la interfície.

Per a més informació, consulteu la [documentació](https://go.microsoft.com/fwlink/?LinkId=761051).

#  Catalan Language Pack for VS Code

The Catalan Language Pack provides a localized UI experience for VS Code.

## Usage

You can override the default UI language by explicitly setting the VS Code display language using the **Configure Display Language** command.

Press `Ctrl+Shift+P` to bring up the **Command Palette** then start typing `display` to filter and display the **Configure Display Language** command.

Press `Enter` to display a list of installed languages, with the current language highlighted. Select another language to switch UI language.

See [Docs](https://go.microsoft.com/fwlink/?LinkId=761051) for more information.
